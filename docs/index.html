gomi is a trash can for the command line. Use it like rm. Nothing is gone until you empty it, and rm -b brings things back to where they were.

Throw a file in, then look inside the can.

Your rm habits stay.

Put alias rm=gomi in your shell config. The flags you know keep their meaning, and the trash is the same XDG trash your desktop and trash-cli use. Linux, macOS and Windows.

rm file

Into the can, not into oblivion.

rm -rf dir/

Directories too, without a prompt.

rm -i *.log

Asks before each file.

gomi --prune=30d

Empties what is older than 30 days. --dry-run looks first.

Pick up a can.

curl -fsSL https://gomi.dev/install | bash

Puts the binary in ~/bin. Set PREFIX to change it.
